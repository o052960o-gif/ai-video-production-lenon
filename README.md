# AI Video Production Workflow - LENON Project

## Overview
This repository showcases my AI-powered video production workflow using tools like imageFX and Kling.
The project focuses on creating emotionally engaging, realistic, and slightly humorous short videos featuring a newborn black Labrador puppy named LENON.

## Concept
- Theme: Warmth of handmade life & emotional storytelling
- Style: Realistic + Cute + Cinematic
- Format: Short-form video (YouTube Shorts / Reels / TikTok)

## Project Example
"Little Farmer - Popcorn Story"

A 12-scene story where LENON discovers corn, struggles with taste, and creatively turns it into popcorn.

## Workflow
1. Idea & Story Design
2. Storyboard Creation (12 scenes)
3. Image Generation (imageFX)
4. Animation / Motion (Kling)
5. Editing (FCP)
6. Sound Design & Final Output

## Tools Used
- imageFX (image generation)
- Kling (animation)
- Final Cut Pro (editing)

## Key Strengths
- Structured storytelling
- Prompt engineering for consistent character output
- Cinematic pacing for short-form content
- Emotional + humorous balance
